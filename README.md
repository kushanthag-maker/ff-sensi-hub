# FF Sensi Hub ⚡

Free Fire Auto Headshot Sensitivity & DPI Generator Web App.

## 🚀 Features
- **Smart Sensi Engine:** Generates custom sensitivity (General, Red Dot, 2X, 4X, Sniper, Free Look) based on Device Brand, RAM size, Refresh rate & Playstyle.
- **DPI & Fire Button Size Calculator:** Gives precise recommended button sizes and safe DPI ranges.
- **Pro Drag Tricks:** Inbuilt headshot tricks and tips.
- **Copy to Clipboard:** One-tap copy feature to share or apply settings.
- **Vercel Ready:** Fully configured with `vercel.json` for zero-config instant deployment.

## 🛠️ Deploy to Vercel
1. Fork / push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import this repository and click **Deploy**.

## 💻 Local Development
```bash
npm install
npm run dev
```
