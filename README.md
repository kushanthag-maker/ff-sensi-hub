# FF Sensi Hub ⚡

Free Fire Auto Headshot Sensitivity & DPI Generator Web App.

## 🚀 Deployment on Vercel
1. Go to [Vercel](https://vercel.com).
2. Click **Add New** ➔ **Project**.
3. Select the `ff-sensi-hub` repository.
4. Keep default settings (Framework: Vite, Build Command: `vite build`, Output Directory: `dist`).
5. Click **Deploy**.
